# 치지직 신삼국지 같이 보기 예고편 스포일러 방지용 크롬확장

치지직에서 영상이 끝나기 30초 전부터 영상 화면을 검게 만듭니다 (다음 화 예고편 스포 방지).
소리와 플레이어 버튼(다음 화, 재생바 등)은 그대로 두고, 다음 화가 시작되면 자동으로 풀립니다.

## 설치

1. 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → `chzzk-last30` 폴더 선택
5. 치지직 탭 새로고침 → 왼쪽 아래에 🛡 표시가 생깁니다.

(예전 "예고편 가리개"를 설치했다면 확장 페이지에서 끄거나 삭제하세요. 둘 다 켜져 있으면 패널이 두 개 보입니다.)

## 사용

- 왼쪽 아래 🛡 줄을 클릭하면 설정이 열립니다: 켜기/끄기, 끝에서 몇 초 가릴지(기본 30초)
- 가려진 화면의 **그냥 보기**: 이 화는 더 이상 가리지 않음
- **Alt+B** (맥은 Option+B): 언제든 바로 가리기/풀기
- 되감아서 마지막 30초 밖으로 나가면 풀리고, 다시 들어오면 가립니다.

## 안 될 때

🛡 줄에 **"길이를 알 수 없어서(라이브) 가릴 수 없어요"**가 나오면, 그 플레이어가 영상 끝 시점을 알려주지 않는 라이브 스트림이라 이 방식으로는 가릴 수 없습니다. Alt+B로 직접 가려 주세요.

크롬이 설치할 때 "모든 사이트의 데이터 읽기" 권한을 묻는 건, 같이보기 영상이 다른 주소의 플레이어(iframe) 안에서 재생될 수 있어서입니다. 실제로는 치지직 페이지 안에서만 동작합니다.
